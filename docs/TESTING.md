## 测试覆盖

**纯逻辑（tests/logic）**
- 命中率计算与 0 出手处理；训练 XP 公式、单次上限、恢复训练 XP
- 每日 XP 上限按记录顺序分配
- 等级阈值边界、最高等级、称号映射、等级进度
- 测试评分曲线插值 / 截断 / 用时类反向评分
- 能力取最近一次测试、保留历史最好、未测试显示预估、按日期回溯
- 五个位置权重之和为 1、位置影响 OVR
- 训练输入校验：命中 > 出手、未来日期、非法日期、时长范围、出手密度、次数类项目
- 球员、测试、比赛输入校验
- 恢复日判定（连续训练、恢复训练不计入、高负荷）
- 每日任务可复现、恢复日任务、任务进度过滤
- 4 周赛季切分、赛季评级、连续天数、徽章等级

**服务与数据库（tests/db）**
- 球员只能创建一次，创建时生成快照
- 提交训练：命中率、XP、XP 流水与事件
- 拒绝不合理成绩
- 修改 / 重复修改 / 删除后 XP 整体重算，不重复发放
- 每日上限生效，删除后额度回流到后续记录
- 累计 XP 触发升级事件
- 徽章由真实数据解锁、删除数据后收回
- 任务需完成才能领取、只能领取一次、过期不能领取
- 能力测试评分、刷新纪录事件、普通训练不改变能力评分
- 球商问答服务端判分、拒绝伪造题目与不完整答卷
- 助攻失误比需要 ≥ 3 场比赛
- 赛季信息、赛季总结、跨赛季后弹出结算并可标记已读
- 统计数据来自真实记录
- 导出 / 导入往返一致，不导出 API Key，拒绝无效备份
- **持久化：关闭并重新打开数据库文件后数据完整**
- AI：无 Key 走本地规则并标注；有 Key 时请求头与上下文正确、上下文只含真实记录；401 错误信息不泄露密钥并自动回退；拒绝非 https 远程地址

## 尚待在 Windows 本机完成的验证

以下步骤需要 `npm install` 后执行（命令见 README）：

1. `npm run typecheck` —— 含 React / Electron / Motion 依赖的完整类型检查
2. `npm test` —— 用真实 vitest + Electron 内置 Node + better-sqlite3 重跑上面 64 个测试
3. `npm run dev` —— 界面与动效人工验收（按钮压缩回弹、菜单滑块、页面切换、徽章 / 升级动画、减少动效选项）
4. `npm run dist:win` —— 生成 NSIS 安装程序并安装验证
